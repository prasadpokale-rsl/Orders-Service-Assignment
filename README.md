# Order Service

This is a Spring Boot application that uses HashiCorp Vault to manage database credentials and an external API key.

## Requirements

* Java 17
* Maven
* PostgreSQL
* HashiCorp Vault

## Vault Setup

Start Vault and set the Vault address:

```bash
export VAULT_ADDR=http://127.0.0.1:8200
```

Enable the database secrets engine:

```bash
vault secrets enable database
```

Configure the PostgreSQL connection:

```bash
vault write database/config/order-service-db \
  plugin_name=postgresql-database-plugin \
  connection_url="postgresql://{{username}}:{{password}}@localhost:5432/orders?sslmode=disable" \
  allowed_roles="order-service-role" \
  username="postgres" \
  password="postgres"
```

Create the database role:

```bash
vault write database/roles/order-service-role \
  db_name=order-service-db \
  creation_statements="CREATE ROLE \"{{name}}\" WITH LOGIN PASSWORD '{{password}}' VALID UNTIL '{{expiration}}'; GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO \"{{name}}\";" \
  default_ttl=30m \
  max_ttl=1h
```

Store the API key in Vault:

```bash
vault kv put secret/order-service external.api.key="sample-api-key"
```

Create the application policy:

```bash
vault policy write order-service vault-order-service-policy.hcl
```

Create a token using this policy:

```bash
vault token create -policy=order-service
```

Copy the generated token and set it as an environment variable.

### Windows PowerShell

```powershell
$env:VAULT_TOKEN="your-vault-token"
```

The application reads the token using:

```properties
spring.cloud.vault.token=${VAULT_TOKEN}
```

The Vault token should not be added directly to `application.properties` or committed to Git.

## Run the Application

From the project folder:

```bash
mvn spring-boot:run
```

## API Endpoints

### Create an order

```bash
curl -X POST http://localhost:8080/orders -H "Content-Type: application/json" -d "{\"product\":\"Widget\",\"quantity\":2}"
```

### Get orders

```bash
curl http://localhost:8080/orders
```

### Call external API

```bash
curl http://localhost:8080/external/call
```

## Check Dynamic Credentials

To see the credentials generated by Vault:

```bash
vault read database/creds/order-service-role
```

Run the command again to get a new set of credentials.

## Revoke a Credential

```bash
vault lease revoke <lease_id>
```

The `lease_id` can be taken from the output of the credentials command.
